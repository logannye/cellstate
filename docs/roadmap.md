# Roadmap

1. **Contracts and reproducibility** — schemas, event history, provenance, CI, and round trips.
2. **Reference estimator** — recursive Gaussian filtering, controlled evolution, sampling, and
   synthetic integration tests.
3. **Asynchronous multimodal adapters** — artifact stores, UCUM-aware units, AnnData/Zarr/Arrow,
   modality-private evidence, and censored likelihoods.
4. **Hybrid dynamics** — event hazards/jumps, division and inheritance, lineage branching,
   neighborhood transport and interaction models.
5. **Scientific diagnostics** — prospective sufficiency, calibration, OOD, identifiability, and
   decision-relevant assay value.
6. **First biological backend** — one declared system boundary, dataset/model cards, frozen benchmark,
   and held-out interventions/environments.
7. **Planning loop** — risk-aware candidate simulation and intervention/measurement selection.

Each phase must have acceptance tests. A biological model does not graduate because its code runs; it
graduates after query-aligned intervention prediction, calibration, OOD, and history-sufficiency
evidence.
